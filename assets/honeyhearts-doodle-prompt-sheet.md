# HoneyHearts — Receipt Doodle Prompt Sheet

Every prompt below is built on the **oval-lavender formula** — the one that gave you clean,
consistent pencil width without washout or grain.

## The formula (why it works)

Four load-bearing phrases appear in every pen-line prompt:

1. `casual marker-pen style`
2. `even line weight` ← consistent pencil width
3. `smooth, deliberate stroke with a slightly organic hand-drawn wobble` ← doodle feel, not vector
4. `clean crisp edges, no sketchy or broken lines` ← clean, not grainy

And the golden rule: **never mention translucency, "see-through", "feathered edges", or
"brush-pen / felt-tip".** That language is what caused the washout and grain.

## Processing (same for all)

- Generate **large** on a plain white background.
- For width consistency, optionally attach `doodle-oval-lavender.png` as a style reference
  and add: _"match the exact line thickness and pen style of the attached reference."_
- These come out clean, so run **key-only** (no boost):
  `python3 boost_doodle.py in.png out.png --keyonly`
